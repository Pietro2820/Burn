# 🤖 Burn v1.0 - Assistente Virtual de Produtividade

O Burn é um protótipo de assistente virtual que avalia sua disposição e sugere tarefas adequadas ao seu nível de energia.

## 🎯 Funcionalidades
- Avalia seu nível de disposição (baixa, média ou alta)
- Sugere tarefas personalizadas baseadas na sua energia
- Validação de entrada (não aceita letras ou números inválidos)

## 🚀 Como rodar
```bash
python burn.py
